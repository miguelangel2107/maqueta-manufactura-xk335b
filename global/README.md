# Recursos globales

Archivos que describen la planta y no pertenecen a un semestre en particular.

| Carpeta                 | Contenido |
|-------------------------|-----------|
| `datasheets/`           | Hojas de datos y manuales de fabricante: S7-200, servo Panasonic MINAS A4, variadores Powtran, sensores Omron y SMC, cilindros, borneras, librería Modbus. |
| `manuales/`             | Manual original de la XK-335B (inglés). |
| `programas-originales/` | Programas de fábrica de las cinco unidades para STEP 7-Micro/WIN. |
| `modelos-3d/`           | `autocad/`: modelos hechos en 2023-II. Los modelos en SolidWorks de II-2026 van en `solidworks/`. |
| `software/`             | Enlaces a Google Drive para STEP 7-Micro/WIN V4 SP9 y la librería USS/Modbus. |

Antes de agregar un datasheet, revise que no esté ya en `datasheets/`. Para indicar a qué unidad corresponde, agréguelo en `config/archivos.json`.
