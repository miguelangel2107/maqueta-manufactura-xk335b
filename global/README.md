# Recursos globales

Archivos que describen la planta y no pertenecen a un semestre en particular.

| Carpeta                 | Contenido |
|-------------------------|-----------|
| `datasheets/`           | Hojas de datos y manuales de fabricante: S7-200, servo Panasonic MINAS A4, variadores Powtran, sensores Omron y SMC, cilindros, borneras y librería Modbus. |
| `manuales/`             | Manual original de la XK-335B (inglés). |
| `programas-originales/` | Programas de fábrica de las cinco unidades para STEP 7-Micro/WIN. |
| `modelos-3d/`           | `autocad/`: modelos de 2023-II. `solidworks/`: modelos de II-2026. |
| `software/`             | STEP 7-Micro/WIN V4 SP9 y librería USS/Modbus (enlaces a Google Drive). |
